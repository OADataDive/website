# Website

Static HTML/CSS portfolio with Home, Certifications, Publications, and Projects pages.

## Run from Terminal

Open Terminal and enter the project folder, then run:

```bash
./start-site.command
```

The Terminal prints:

```text
Personal homepage is running at:
http://localhost:8000
```

Command-click `http://localhost:8000` on macOS to open the site.

Alternatively:

```bash
echo "http://localhost:8000" && python3 -m http.server 8000 --bind 127.0.0.1
```

Stop the server with Control+C.
